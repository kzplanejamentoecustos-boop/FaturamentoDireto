⬇ Exportar para Excel

Exportar Tudo gera uma cópia funcional do controle: mesmo visual, logos, totais e indicadores calculados por fórmulas, listas suspensas e conferência de saldos. As demais opções exportam uma aba simples para consulta.

⬆ Importar do Excel
Como usar:
1. Clique em "Exportar Tudo" para baixar o modelo com abas e instruções
2. Preencha os dados — em Terceiros use o nome exato da Atividade Contratual; nas NFs use o nome exato do Terceiro
3. Para NFs: preencha também o "Nº Pedido de Compra" do terceiro
4. Não altere os nomes das colunas nem das abas
5. Selecione o modo e importe o arquivo aqui

💡 A coluna ID pode ser deixada em branco — o sistema vincula por nome automaticamente. Planilhas antigas (com Fornecedor Principal) continuam sendo aceitas: os fornecedores são descartados e os terceiros são mantidos.
