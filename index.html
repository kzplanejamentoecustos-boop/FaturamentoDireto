⬇ Exportar para Excel

Baixe os dados em planilha Excel (.xlsx) com abas separadas para cada tipo de cadastro. Use para consulta, revisão ou preenchimento de novos registros.

⬆ Importar do Excel
Como usar:
1. Clique em "Exportar Tudo" para baixar o modelo com abas e instruções
2. Preencha os dados — use o nome exato do fornecedor na coluna "Fornecedor Principal"
3. Para NFs: preencha "PC Fornecedor" com o número exato do pedido e "Terceiro" com o nome exato
4. Não altere os nomes das colunas nem das abas
5. Selecione o modo e importe o arquivo aqui

💡 A coluna ID pode ser deixada em branco — o sistema vincula por nome do fornecedor e número do pedido automaticamente.
